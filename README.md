# منيو بلس — MenuPlus (menuplus.rest)

منصّة **متعددة المطاعم** (multi-tenant) — كل مطعم/مقهى يحصل على منيوه الرقمي الخاص على رابط
`/<اسم-المطعم>`، بعلامته وألوانه وطاولاته وطلباته. مبنية على Next.js 16 + Supabase.

## يعمل الآن بلا قاعدة بيانات
شغّله مباشرة وسترى مطعمين تجريبيين:

```bash
npm run dev
```

- الصفحة الرئيسية: `http://localhost:3000`
- منيو مقهى تجريبي: `http://localhost:3000/dallah`
- منيو مطعم تجريبي: `http://localhost:3000/sham?t=5` (مع رقم طاولة)

كل مطعم بلونه ومنيوه المستقل — dallah على **الباقة الأساسية** (منيو عرض فقط، قالب 5) و sham على **الباقة الشاملة** (كل الميزات، قالب 1).

## الباقات
- **باقة الانطلاق** — مجاناً (15 عنصراً / 5 أقسام).
- **الباقة الأساسية** — 25,000 د.ع شهرياً (100 عنصر / 15 قسماً).
- **باقة التميز** — 35,000 د.ع شهرياً (بلا حدود + الطلبات من القائمة).
- **الباقة الشاملة** — 50,000 د.ع شهرياً (كل شيء + إخفاء الحقوق).
- السنوي = ×10 (شهران مجاناً).

الجدول في الصفحة الرئيسية مطبّق فعلياً — الصلاحيات تُفرض من قاعدة البيانات (triggers + RLS) ومن الواجهة.
أهم البوابات: الطلبات من باقة التميز فصاعداً · الحجز والعروض تطبيقات تُفعَّل من المتجر (مضمّنة في الشاملة) · إخفاء حقوق منيو بلس للشاملة فقط.

## لربط قاعدة بيانات حقيقية (Supabase جديد)
1. أنشئ مشروع Supabase جديداً على supabase.com.
2. من **SQL Editor** شغّل ملفات `supabase/migrations/` بالترتيب (`0001` → `0006`).
3. انسخ `.env.example` إلى `.env.local` واملأ:
   - `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` (Project Settings → API)
   - `SUPABASE_SERVICE_ROLE_KEY` (السري — للطلبات فقط)
4. أضف مطاعمك وأصنافك في جداول `restaurants` / `categories` / `menu_items`.
5. لتغيير باقة مطعم:
```sql
update public.restaurants set plan = 'premium' where slug = '...';
```

بمجرد ضبط المتغيّرات تتحوّل المنصّة تلقائياً من البيانات التجريبية إلى قاعدة البيانات الحقيقية.

## للنشر (Netlify جديد)
اربط المستودع بموقع Netlify جديد وأضف متغيّرات Supabase الثلاثة في إعداداته. `netlify.toml` جاهز.

## لوحة إدارة المطعم — `/admin`
حساب مستقل لكل مطعم. الدخول من `/sign-in`، وبعده تظهر التبويبات:
- **الطلبات** — إشعارات فورية عبر Supabase Realtime، مع تنفيذ/إلغاء.
- **الحجوزات** — تأكيد/رفض.
- **المنيو** — أقسام وأصناف: إضافة، تعديل، حذف، ترتيب (↑↓)، إخفاء صنف مؤقتاً، وأحجام بأسعار مختلفة.
- **الإحصائيات** · **التقييمات** · **المتجر** (تفعيل تطبيقي الحجز والعروض).
- **الإعدادات** — استقبال الطلبات · طرق الطلب · حجز الطاولات · تبديل القالب (1–6، مع معاينة `?tpl=`) · إضافة مشرفين (`addAdmin`).

**إنشاء حساب لمطعم:**
1. Supabase → Authentication → Add user (بريد + كلمة مرور).
2. اربطه بالمطعم من SQL Editor:
```sql
update public.restaurants
set owner = (select id from auth.users where email = 'owner@example.com')
where slug = 'sham';
```

العزل مضمون من قاعدة البيانات نفسها (RLS): كل حساب يرى صفوف مطعمه فقط —
حتى لو حاول استدعاء الـ API مباشرة.

الحجوزات تصل إلى جدول `reservations` (الاسم، الهاتف، التاريخ، الوقت، عدد الأشخاص، ملاحظة).

## القوالب
6 قوالب لواجهة المنيو، تُبدَّل من الإعدادات:
1. **اللوحي الداكن** · 2. **بطاقات الأقسام** · 3. **الفاخر** · 4. **الداكن السريع** · 5. **المدمج** · 6. **الدافئ**

## البنية
- `src/app/page.tsx` — الصفحة التعريفية + المطاعم التجريبية.
- `src/app/[slug]/page.tsx` — منيو مطعم واحد.
- `src/components/TenantMenu.tsx` — واجهة المنيو (سلة + طلب)، تتلوّن بلون المطعم وتتبدّل قوالبها.
- `src/lib/plans.ts` — مصدر الحقيقة للباقات والأسعار والبوابات.
- `src/lib/menu-data.ts` — طبقة البيانات (قاعدة حقيقية أو تجريبية).
- `src/lib/actions.ts` — `placeOrder` + `reserveTable`.
- `src/app/sign-in/page.tsx` · `src/app/admin/` — دخول المطعم ولوحة إدارته.
- `supabase/migrations/` — `0001` → `0006` بالترتيب.

## القادم
رفع الصور إلى Supabase Storage · ربط مزوّد واتساب (الكود جاهز في `src/lib/notify.ts` عبر `WHATSAPP_TOKEN`/`WHATSAPP_PHONE_ID`) · الدفع الإلكتروني والاشتراك الذاتي.
